# Code of conduct

## Our standard

Be respectful, precise, and constructive. Disagreement about security claims is
welcome when it is evidence-based. Harassment, threats, discrimination,
doxxing, deliberate exposure of secrets, and unsafe demonstrations using other
people's funds or devices are not acceptable.

## Scope

This standard applies in repository issues, pull requests, reviews, discussions,
and project-related public communication.

## Enforcement

Report conduct concerns privately to the repository maintainer. The maintainer
may edit or remove content, close discussions, reject contributions, or block
participants when needed to protect the community and users. Good-faith
security reports handled under `SECURITY.md` will not be penalized.
