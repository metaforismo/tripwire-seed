# Independent reproduction reviewer notes

The reviewer should not receive or request any Tripwire Seed mnemonic,
passphrase, SeedQR, private key, complete account xpub, descriptor, address, or
wallet file. Reproduction evidence is entirely public build information.

Review the frozen commit, artifact identifiers, source-acquisition method,
separate administration claim, complete toolchain, build commands, verifier
report, and mismatch analysis. Confirm that the report's raw executable equality
is not being presented as proof of trusted compilers, other targets, wallet
interoperability, or a security audit.

A reviewer who participated in administering the original GitHub build or the
reproduction host should disclose that limitation rather than describing the run
as independently reviewed.
