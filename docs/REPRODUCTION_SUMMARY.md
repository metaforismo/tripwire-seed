# Independent reproduction summary

1. Freeze one commit and native target.
2. Verify the GitHub reference artifact and attestation.
3. Build the reviewed source on a separately administered system.
4. Produce two identical local native builds with the repository packager.
5. Compare the complete reproduced executable with the reference using the
   inspection-first verifier.
6. Explain every mismatch.
7. Publish only privacy-safe evidence.
8. Obtain second-person review.

This sequence must be completed independently for Linux, macOS, and Windows.
