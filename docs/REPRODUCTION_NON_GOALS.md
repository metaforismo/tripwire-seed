# Reproduction non-goals

The reproduction helper is not intended to:

- generate, import, or inspect wallet secrets;
- execute the downloaded reference binary;
- create a sandbox for arbitrary executables;
- verify GitHub attestations itself;
- authenticate a source checkout;
- prove administrative independence;
- normalize binaries or compare selected sections only;
- certify external wallet applications;
- replace the first stable-release security audit; or
- authorize a stable tag or use with meaningful funds.

Those boundaries are intentional. Keeping the helper narrow makes its positive
result easier to interpret and harder to overstate.
